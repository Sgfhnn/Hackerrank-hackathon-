## How the cost is estimated

Cost = (non-cached input tokens x input price + cached input tokens x cached price + output tokens x output price) / 1,000,000, using the per-model USD prices configured in `PRICING`. Average tokens per request divides total tokens by the number of requests above, not by the number of model calls.
